## 优化顺序

1. 直方图与桶扫描：先检查主仓对 SIMD 统计和扫描的实际表达能力，按可用能力做最小实现和实测。
2. FP16 粗桶、FP32 精确细化：验证完整输入域的顺序规则，保留候选溢出重扫与同分索引确定性。
3. UB 分块搬运：分别核实批量搬运与计算收益，不把候选 ping-pong 当成输入流水。
4. 调度：分别评估 Prefill worker 数和 Decode 行内并行。

每轮保存独立提交及标签。若正确性失败或性能回退，记录失败原因，并恢复最佳已验证实现；不将回退实验伪装为有效优化。
